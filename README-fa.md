### 🐍 نمودار متحرک کانتریبیوشن (Snake)

برای این‌که یه مار متحرک روی خونه‌های سبز کانتریبیوشنت بخزه:

1. توی همون ریپوی `saeedshamc/saeedshamc`، مسیر `.github/workflows/snake.yml` رو با این محتوا بساز:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch: {}
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        id: snake-gif
        with:
          github_user_name: saeedshamc
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

2. یه بار از تب Actions اجراش کن (workflow_dispatch) تا برنچ `output` ساخته بشه.
3. این تگ رو هرجا خواستی توی README بذار:

```markdown
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/saeedshamc/saeedshamc/output/github-contribution-grid-snake-dark.svg" />
  <img alt="snake animation" src="https://raw.githubusercontent.com/saeedshamc/saeedshamc/output/github-contribution-grid-snake.svg" />
</picture>
```
